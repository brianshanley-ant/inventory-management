Where the logic lives

  • Filtering is server-side for inventory, orders and the summary; views also re-derive client-side (Dashboard fetches raw orders and inventory and computes its own KPIs from them).
  • Aggregation is split: /dashboard/summary and /reports/* aggregate in Python, while most charts aggregate in Vue computed properties.
  • Time filter only applies to orders. Inventory has no date dimension, so the month filter is ignored there.
  • Localization is fully client-side. Switching to Japanese swaps strings, the mock user, and formats currency as JPY. The API always returns USD figures.

State model

  • No store. Shared state is module-level ref()s exported from composables, which makes each composable a singleton across components.
  • Filters and locale persist for the session; locale also persists to localStorage.
  • Backend state is the Python process. Any mutation (none exist today) would vanish on restart.
  • Views own their fetch lifecycle: onMounted load, watch on filters, local loading/error refs.

Data model

InventoryItem · 32

id, sku, name, category, warehouse, quantity_on_hand, reorder_point, unit_cost, location, last_updated

Low stock = quantity_on_hand ≤ reorder_point. Categories: Circuit Boards, Sensors, Actuators, Controllers, Power Supplies.

Order · 250

id, order_number, customer, items[], status, warehouse, category, order_date, expected_delivery, actual_delivery, total_value

Status: Delivered, Shipped, Processing, Backordered. Dates are YYYY-MM-DD strings; month filtering is substring-based.

DemandForecast · 9 / BacklogItem · 4

item_sku, current_demand, forecasted_demand, trend, period · order_id, quantity_needed, quantity_available, days_delayed, priority

Backlog rows are joined to purchase_orders.json at request time to set has_purchase_order.

Observations

Strengths

  • Very small surface: one backend file, one API client, a handful of views. Easy to read end to end in an hour.
  • Consistent filter contract across client and server ('all' means unfiltered everywhere).
  • Composables give shared state without a store dependency.
  • Pydantic models document the data shape and catch drift between JSON and code.
  • Detailed CLAUDE.md files at root, client, and server explain conventions for agent-assisted work.

Gaps and rough edges

  • bug Tasks and purchase-order calls in api.js hit routes that don't exist. The tasks modal swallows the error and shows only mock tasks.
  • inconsistency Reports.vue calls axios directly with a hard-coded URL instead of going through api.js.
  • dead code Backlog.vue exists but has no route; backlog data surfaces only on the Dashboard.
  • duplication Dashboard fetches raw orders and inventory and recomputes KPIs the summary endpoint already provides.
  • size Dashboard.vue is 1,271 lines and Spending.vue is 852; both mix data loading, chart math and SVG markup.
  • hard-coded Quarter map and revenue goals are 2025-specific literals in Python and Vue.
  • No auth, wildcard CORS, no persistence, no pagination. Fine for a demo, not beyond it.
